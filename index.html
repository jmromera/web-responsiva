Los 6 conceptos de esta página

Unidades relativas · contenedor width: 90%; max-width: 72rem → ahora
  • 1. Diseño responsivo

    Una sola página que se adapta a móvil, tablet y escritorio. Empieza en móvil (mobile first) y amplía con min-width. Lo ves en el panel de arriba.

  • 2. Rejillas fluidas

    CSS Grid decide cuántas columnas caben sin media queries: auto-fit + minmax(16rem, 1fr).

  • 3. Unidades relativas

    % para anchos, rem/em para textos y espacios, fr para repartir columnas y clamp() + vw para tipografía fluida.

  • 4. Media queries

    Dos puntos de corte: 40rem (640px, tablet) y 64rem (1024px, escritorio).

  • 5. Contenido adaptable

    En móvil se oculta la descripción de las tarjetas para priorizar lo esencial.

  • 6. Imágenes flexibles

    max-width: 100%; height: auto + aspect-ratio: la imagen nunca se sale de su caja.
